Internal Tool

Ads Manager Dashboard

A self-built dashboard that runs the day-to-day management of my Google Ads account — monitoring, automation, and tracking hygiene in one place, powered by the official Google Ads API.

What it does

Campaign Monitoring

A single overview of spend, clicks, conversions, and return on ad spend across every campaign, with daily trends for the last 30 days.

Spend Guardrails

Automated rules that watch the account on a schedule — pausing campaigns that burn budget without converting, and flagging abnormal cost-per-conversion movement.

Search-Term Hygiene

Pulls the search terms report, flags queries that spend without converting, and adds them as negative keywords directly from the tool.

Tracking Management

Manages Final URL Suffixes and tracking parameters across campaigns, including scheduled rotation of tracking values for clean attribution.

Audit Change Log

Every automated or manual action the tool takes is recorded — what changed, on which campaign, when, and why — so nothing in the account is ever a mystery.

Campaign Controls

Pause and enable campaigns from the dashboard, with each action validated and written back to the account through the API.

Inside the tool

Overview

The landing view: headline KPIs for the account, daily spend and conversion trends, and per-campaign performance at a glance.

Campaigns

Per-campaign budgets, performance, and status controls. Pausing or enabling a campaign takes effect in the account through the API and is written to the change log.

Guardrails

Automation rules with configurable thresholds. Enabled rules run against the account on a schedule and act through the API.

Search Terms

The search terms report with wasteful queries flagged. Adding a negative keyword is a single action, and it is written to the account immediately.

Tracking

Final URL Suffix management per campaign, with scheduled rotation of tracking values and a history of every rotation applied.

Change Log

The audit trail: every action taken by the tool — guardrail triggers, suffix rotations, status changes — with timestamps and details.

How it uses the Google Ads API

The dashboard talks to a single Google Ads account — my own — using the official Google Ads API with OAuth 2.0 credentials. It does not access any other account, and it is not offered to anyone else.

  • GoogleAdsService — reporting queries for campaign performance and search term reports.
  • CampaignService — reading and updating campaign settings, including status and Final URL Suffixes.
  • CampaignBudgetService — reading budget configuration for pacing checks and guardrails.
  • AdGroupCriterionService — adding negative keywords identified from the search terms report.

Request volume is modest — scheduled report queries a few times per hour and occasional mutations when a guardrail triggers or a setting changes.

Scope and data handling

This is an internal tool, operated by me and used only on my own advertising account. Data retrieved through the API is stored locally, never shared with third parties, and never used for any purpose other than managing that account. Details are in the privacy policy.
