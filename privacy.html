Privacy Policy

Last updated: 28 August 2026

This privacy policy applies to the Google Ads management tool operated by Lưu Thị Quỳnh Hương ("we", "us"). The tool is used internally to manage our own Google Ads advertising account.

Information we access

The tool uses the official Google Ads API to read and update settings within our own Google Ads account — specifically, campaign settings such as the Final URL Suffix. It accesses this data using OAuth 2.0 credentials belonging to our own Google account.

How we use information

Information accessed through the Google Ads API is used solely to update campaign settings in our own account. We do not use it for any other purpose.

Data sharing

We do not sell, rent, or share any data accessed through the Google Ads API with any third party. The tool is not offered to, or used by, any other person or organization.

Data storage and retention

The tool runs on a private computer under our control. OAuth credentials and configuration are stored locally and are not transmitted to any party other than Google's own API endpoints. We retain only the operational data needed to run the tool (such as configuration and activity logs).

Google API Services User Data Policy

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
